可做研究点

复现并比较“文本反思”与“表示反思”在技能修订中的误差定位能力

Rep2Skill 的关键主张不是泛泛提升性能，而是更准确定位失败发生在哪个 turn。这个点可直接检验其是否真正优于只看文本轨迹的方法，也能帮助判断内部表示是否提供了独立信息。

第一步：选一个公开 agent 环境，收集成功/失败 rollouts；先不实现完整方法，只做一个最小分析：比较基于文本启发式与基于隐藏状态相似度/偏离度的失败 turn 排名，与人工标注失败关键步的一致性。

风险：论文可能依赖特定模型内部接口或专门的表示处理方法；若没有公开代码，简单隐藏状态距离未必能复现其效果。

做一个“程序化环境模型 vs 自然语言笔记”小型对照基准

Schema 的核心命题很清楚：在未知环境中，可执行程序比散文式记忆更紧凑、可检验、利于规划。这个命题适合做小规模独立验证，也容易产出负结果或边界条件。

第一步：从 MazeBench 或一个简单规则发现游戏中抽取 10-20 个任务，固定同一基础模型，分别给它自然语言工作区和可执行程序工作区，比较规则发现正确率、后续规划成功率、上下文长度占用。

风险：程序工作区的接口设计本身会强烈影响结果；若执行器或一致性检查器做得太强，比较可能不公平。

分析多代理社会学习失败是否主要由 token 预算分配不当导致

From Solo to Social Learning 的价值在于负结果和机制解释。一个直接可做的后续是把“社会学习无效”拆成探索不足、复制对象选择差、复制成本过高等更细原因。

第一步：在一个可控多代理环境中复现实验设定，加入预算审计：记录每个代理在搜索、观察、复制、执行上的 token 开销，并做简单干预，如强制上限观察预算或固定复制频率，观察单位 token 回报是否改善。

风险：原论文环境和 skill file 机制可能不易复现；若任务太简单，社会学习与独立学习差异会被掩盖。

把 APTInvestBench 的“证据可见性—证据获取—正式引用”三层失败分解迁移到其他 agent benchmark

这类评测思想比单一安全场景更普适。很多 agent benchmark 只看最终答案，无法区分环境不可见、检索失败、推理失败、报告失败。迁移这套分解框架有望提升评测诊断力。

第一步：选一个已有检索型 agent 任务集，手工为少量样本定义最小证据支持要求，并把失败拆成‘证据不存在/不可见’、‘证据存在但未找到’、‘找到但未在最终答案中正确使用’三类，做一次小样本误差分析。

风险：其他 benchmark 未必有清晰的记录级证据对象，人工标注成本可能较高。

检验自适应指令采样是否真的优于均匀采样，尤其在模型能力变化阶段

多 LLM 协同对齐论文的创新点集中在采样策略和声誉加权，但这类方法常受实现细节影响。做一个小规模消融，能快速判断收益来自 bandit 采样、对手匹配还是偏好学习本身。

第一步：在一个中等规模指令集上，用 2-3 个开源模型搭建最小互评训练循环，只比较均匀采样与基于难度/可区分性的简单 bandit 采样，先看偏好数据质量和训练后 win-rate 是否提升。

风险：多模型互评噪声很大，若评审质量不稳定，采样策略差异可能被淹没；训练成本也可能偏高。

围绕 beam search 理论中的 coverage coefficient 做经验测量

Provable Test-Time Scaling 给出的理论量如果无法经验估计，实际指导意义会受限。做经验代理指标，有助于把理论与真实推理任务连接起来。

第一步：在一个可自动判分的推理数据集上，记录正确解路径前缀在不同 beam 宽度下的存活率，并尝试用 token 概率覆盖、前缀排名稳定性等可观测指标近似 prompt 难度，分析其与最终搜索收益的相关性。

风险：理论定义的系数可能难以直接观测，经验代理指标未必对应论文中的正式量；结论可能只能是相关而非验证。

完整解释

从题名和摘要看，论文研究对象非常具体：不是一般的 LLM 微调，也不是单次推理增强，而是“LLM agent 的文本技能自进化”。这里的“技能”应指可被智能体反复调用的文本化程序知识、策略描述或操作规则，其优势是不需要更新模型参数即可积累经验。论文指出现有方法主要停留在文本空间：优化器只能从长执行轨迹和稀疏任务结果中总结成功/失败模式，再去改写技能文本。这种做法的问题是，智能体在执行中的内部表示已经编码了状态演化、决策偏移和失败征兆，但这些信息没有被用于技能修订。 Rep2Skill 的关键思路是“representation-guided skill self-evolution”。按摘要描述，流程大致包括：先收集 agent rollouts；再对 rollout 对应的内部模型表示轨迹进行建模；通过与成功执行动态对比，定位哪些 turn 偏离了成功轨迹；最后把这些表示层面的异常信号与当时的执行上下文一起解释成可操作的文本反馈，用于定向修订技能。这里至少包含两个技术环节值得重点关注。第一，如何定义和建模“成功执行动态”以及“偏离”：可能涉及隐藏状态序列、层表示、token/turn 级聚合表示、轨迹相似度、时序分类或异常检测。第二，如何把表示空间中的偏差信号转译成自然语言反馈：这一步决定了方法是否真正能服务于外部技能文本更新，而不只是做 post-hoc 分析。 证据线索方面，摘要明确提到在两个 agent 环境和两个开源 LLM 上进行了实验，并且“consistent outperforms text-only approaches”。这说明对比基线大概率是纯文本技能演化/反思/总结类方法，而不是参数更新类方法。由于摘要被截断，暂时无法确认具体环境名称、任务类型、评价指标和提升幅度，但可以合理推测实验会覆盖需要多步决策的 agent 场景，例如交互式环境、工具使用或网页/软件操作类任务，因为这类任务更依赖“turn-level deviation localization”。 如果你的研究方向与 agent memory、self-reflection、test-time adaptation、process supervision 或 mechanistic interpretability 有关，这篇论文的价值在于它尝试把“内部表示分析”直接接到“外部可编辑技能”上，形成一种无需参数更新的自我改进机制。它也可能为表示可解释性提供一个更实用的落点：不是只解释模型为什么失败，而是把解释结果转化为可执行的技能修订建议。 但基于现有信息，仍有几项必须核对。第一，内部表示取自哪个模型、哪一层、哪个粒度，是否需要访问白盒 hidden states；这会直接影响方法对闭源模型和 API 模型的适用性。第二，表示轨迹建模是否需要成功轨迹作为监督，若需要，其数据成本和泛化能力要重点看。第三，文本反馈生成是否依赖额外解释器模型或人工模板。第四，所谓“技能”在实验中具体以什么形式存储和调用，是 system prompt、tool-use guideline、memory item 还是显式 skill library。第五，性能提升是否来自更好的失败定位，还是仅仅因为引入了更多中间监督信号。以上都需要在正文图表和附录中核实。

原始摘要

Textual skills enable large language model (LLM) based agents to accumulate reusable procedural knowledge without updating model parameters. Yet existing skill evolution remains largely confined to the text space: an optimizer must diagnose success and failure patterns, and revise skills solely from long execution trajectories and sparse task outcomes. This text-only paradigm leaves the agent's internal representations, which contain rich records of its evolving execution state, outside the skill optimization loop. We ask whether an agent can improve its external textual skills by reflecting on its own internal representations. We introduce Rep2Skill, a representation-guided framework for self-evolution on agent skills. Specifically, upon the collected agent rollouts, Rep2Skill models their internal model representation trajectories to localize turns that deviate from successful execution dynamics, and it further interprets these signals alongside the execution contexts as actionable textual feedback for targeted skill revision. Experiments on two agent environments with two open-source LLMs show that Rep2Skill consistently outperforms text-only approaches in the self-evolution setting, where the same LLM serves as both executor and optimizer without a stronger external model. This establishes a promising direction moving agent self-improvement beyond text-only reflection.

原始摘要

Coding agents powered by large language models (LLMs) have shown remarkable abilities to autonomously reason about and achieve goals in the digital world. However, bringing this success to the physical world remains challenging. On the one hand, direct generation methods (e.g., Code as Policies) often suffer from the LLMs' insufficient understanding of robots and physical environments. On the other hand, iterative trial-and-error tuning in the physical world (e.g., physical autoresearch) induces significant experimental cost and safety concerns. We introduce SimEX: Simulation-Integrated Robotics AutoResearch, an autoresearch framework that tightly integrates simulated experimentation, enabling coding agents to efficiently acquire physical capabilities for controlling real robots. SimEX operates in two stages. First, the agent conducts open-ended probe-and-optimize iterations in simulation, developing a robot toolbox with robust and generalizable capabilities. Second, the agent adapts the toolbox and the simulator together through only a few physical trials: each trial corrects the simulator, and the corrected simulator is used to diagnose failures and screen candidate repairs. We evaluate SimEX extensively in sim-to-sim settings and on physical robots. On challenging real-world manipulation tasks including towel folding, barcode scanning, and plate manipulation, SimEX enables coding agents to efficiently acquire robot skills without any demonstration and with only 10 minutes of real-robot interaction. These results suggest that simulation can be a critical component in achieving physical intelligence, not only as a source of training data that must closely replicate the real world, but also as a roughly correct laboratory where a coding agent develops the knowledge and procedures needed to act on the robot. 原始摘要

Abstract Carbenes are reactive divalent carbon intermediates that serve as one-carbon synthons to access cyclopropanes. The synthetic utility of these three-membered carbocycles has led chemists to accept the dangers associated with the explosive starting materials 1 or intermediates 2 required for both conventional and modern cyclopropanation reactions. Sulfonium salts, although safer, have not been competitive for cyclopropanation because they typically do not function as efficient carbene donors 3 . In all cyclopropanation reactions reported, diversity can be obtained through either the olefin or carbene partner, but not both; for example, several modern reactions are limited to activated olefins, such as styrenes 4–7 . Here we report how alkylthianthrenium salts differ conceptually from all other carbene precursors and allow for carbene-transfer chemistry, including the synthesis of cyclopropanes, in which both the olefin and the carbene partner can be diverse. The steric bulk and low Lewis basicity of thianthrene can rationalize the superior reactivity of the thianthrenium salts for cyclopropanation because undesired energetically low-lying local minima on the potential energy surface, as present for other sulfonium salts, are avoided. Despite high reactivity, thianthrenium salts exhibit a desirable safety profile that allows scale up, also in the solid state through ball-milling, which is dangerous with many other cyclopropanation reactions. The combination of reactivity and safety highlights thianthrenium ylides as a general compound class for metal–carbene reactivity that extends beyond cyclopropanation to diverse carbene-transfer reactions, including σ -bond insertion and sigmatropic rearrangements.
