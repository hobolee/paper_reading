今天这组论文里，最值得优先读的是一批把“agent 放进可执行环境里”并认真讨论评测与训练机制的工作，整体上比单纯做静态问答或离线指标更接近研究前沿。第一优先级建议放在三篇：NetConfArena、EarthVerse、以及关于 LLM forecasting agents 的综述。原因是它们分别代表了三个当前最关键的问题：如何构造闭环可执行 benchmark、如何评估科学型 agent 的证据使用与工具链、以及如何避免把预测任务中的表面增益误判为真实时序推理能力。NetConfArena 的价值在于把网络配置从“生成命令文本”提升为“在多设备仿真中完成可执行闭环任务并通过隐藏测试验证行为正确性”；EarthVerse 的价值在于把科学任务拆成证据访问、工具选择、记忆、推理、交互与科学执行等可归因模块；预测综述则提醒读者，很多 forecasting 结果可能混杂了检索、工具、污染或评测协议偏差，适合作为后续做该方向实验设计时的防错清单。 第二层值得读的是三篇更偏“训练/机制/基础设施”的论文：ERPO、Terminal Agents、以及 Minimal Local Simulation Foundations。ERPO 试图把 LLM policy optimization 里的正则化重点从 response side 移到 query side，本质上是在讨论 RL 训练时环境分布漂移怎么控，而又不直接压制探索；这类思路对任何交互式 agent 训练都可能有方法学意义。Terminal Agents 则提出一个很重要的经验判断：RL 也许主要不是在教模型新的底层技能，而是在塑造高层决策与技能组合方式；并且 verifier 质量可能比合成环境数量更关键。Minimal Local Simulation Foundations 的定位不是刷性能，而是给出 2D/3D 本地可运行、可改造、教学友好的最小仿真底座，这对做低成本原型验证、课程实验和 agent 失效模式教学很有现实意义。 第三层是应用侧但方法上也有启发的工作。卫星贫困制图那篇虽然不是 agent 论文，但它非常值得做方法借鉴：它把“高精度点预测”推进到“带覆盖率保证的不确定性区间”，对公共政策场景尤其关键。它提醒我们，在很多高风险应用里，单点分数不够，校准和区间才是决策真正需要的输出。Nature 的 addendum 和另外两篇基础科学论文更适合作为领域读物而非今日主线：海平面增补说明因为缺摘要，现阶段只适合跟踪；量子模拟器观测 CFT 谱与颅骨淋巴样结构论文则属于各自领域的重要进展，但与今天这批 agent/environment 方向的共性较弱。 如果从“今天应该先读什么”来排序：第一梯队建议先读 arxiv:2608.23179、arxiv:2608.23525、arxiv:2608.23058；第二梯队读 arxiv:2608.23311、arxiv:2608.22631、arxiv:2608.22833；第三梯队读 arxiv:2608.23322；其余 Nature 论文按各自学科兴趣跟进。总体上，今天的共同信号很清楚：研究重点正在从‘模型会不会答’转向‘agent 能不能在环境里可靠行动、被正确评测、并在分布漂移下保持可解释的能力边界’。

主题线索

从静态文本评测转向可执行、闭环、环境反馈驱动的 agent 基准：NetConfArena 关注多设备网络配置闭环，EarthVerse 关注科学证据检索与执行链，Minimal Local Simulation Foundations 提供 2D/3D 最小环境底座。 agent 能力评测开始强调过程可验证而非答案表面正确：隐藏可执行测试、事件包、answer units、任务 rubric、模块化错误归因，说明 benchmark 设计正在从输出比对转向行为与证据链验证。 训练机制讨论从‘多喂任务’转向‘控制分布漂移与奖励选择性’：ERPO 用 Query-KL 约束输入侧漂移，Terminal Agents 强调 verifier 质量可能比环境规模更关键。 LLM 在预测任务中的真实增益需要重新审视：forecasting agents 综述系统指出工具、检索、污染、微扰敏感性与校准问题，表明很多结果未必来自真正的时序推理。 高风险应用越来越强调不确定性表达与可用性边界：卫星贫困制图使用分位数回归与保形预测提供覆盖率保证，这种思路可迁移到 agent 决策与科学报告场景。

可做研究点

做一个跨 benchmark 的“可执行性评测设计”对照小综述，比较 NetConfArena、EarthVerse 和最小仿真底座这三类环境在动作接口、反馈粒度、隐藏测试、错误归因方式上的异同。

这能快速梳理当前 agent benchmark 从静态 QA 向环境执行迁移时，究竟哪些设计是真正提高了评测可信度，哪些只是换了场景但没有解决验证问题。对后续自建 benchmark 很实用。

第一步：先只基于摘要和可公开页面整理一个 1 页表格，列出每项工作的任务单位、动作空间、环境反馈、最终评分对象、是否可执行验证、是否支持模块化归因。

风险：仅凭摘要可能拿不到足够细节，最终仍需阅读全文或代码仓库确认，且不同 benchmark 面向的任务差异较大，横向比较容易失真。

围绕 Terminal Agents 的论点，设计一个最小复现实验：固定合成终端环境数量，只改变 verifier 质量，观察 RL 后泛化是否比增加环境多样性更敏感。

如果这一结论成立，会直接改变很多 agent RL 工作的资源投入方向：与其扩大任务池，不如优先提升奖励判定质量。这个问题方法学价值很高。

第一步：先不自己训练大模型，可从一个现成小型终端 agent 或开源 trajectory 数据出发，人工构造两版 verifier（宽松版/严格版），在少量任务上做离线重打分与成功轨迹筛选比较。

风险：没有真实训练闭环时，离线分析可能不足以支撑因果结论；同时 verifier 质量的定义不容易操作化，容易和任务难度混淆。

把 ERPO 的“输入侧正则化”思想迁移到可执行 agent benchmark，检查 query/input 分布漂移是否能预测 agent 失稳或过拟合。

很多 agent 训练只盯 response policy，却较少量化训练时模型把自己带向了什么样的查询分布。如果这一指标与性能崩塌、工具误用或长尾失败相关，会是很有价值的诊断工具。

第一步：先做分析型工作，不训练新模型：在一个已有交互轨迹数据集上，统计不同训练阶段或不同 agent 生成的 query/state 描述分布差异，尝试用简单 KL 或 embedding 距离近似漂移。

风险：ERPO 里的 query 分布定义在不同任务上未必直接可比；没有原论文完整公式与实验细节时，迁移可能流于概念类比。

针对 forecasting agents，做一次“增益来源拆分”复核：把纯 LLM、检索增强、工具增强、混合统计模型四类系统的报告结果按任务类型重新整理，区分真正预测能力与外部信息优势。

这个方向目前最容易出现‘看起来很强，但强在别处’的问题。做清楚增益来源，对后续论文设计 baseline 和 claim 边界非常关键。

第一步：选一个具体应用子域，例如天气或金融，只收集近两年的代表性工作，建立一个表格记录输入时间截断、是否可能泄漏未来信息、是否用检索、是否用外部数值模型、指标是否校准。

风险：需要较强的文献筛选纪律，否则很容易变成泛泛综述；此外许多论文不会充分披露污染控制细节，导致判断不稳。

把不确定性估计引入 agent 输出评测：参考卫星贫困制图中的分位数与保形预测思路，为 EarthVerse 或类似科学 agent 任务设计‘答案置信区间/行动风险分层’原型。

科学与政策相关任务不应只有对错二元评价。若 agent 能在证据不足时给出校准后的不确定性表达，实际可用性会比单纯提高准确率更重要。

第一步：先从最简单的后处理开始：收集一个已有 QA/科学任务上的模型置信分数与正确性标签，做保形校准或分箱校准，评估高置信错误是否减少。

风险：agent 任务往往是长链条决策，不像单步预测那样容易定义覆盖率；把保形预测直接迁移到多步工具使用场景有明显方法鸿沟。

尝试用 Minimal Local Simulation Foundations 的思路，自建一个面向教学的超小型本地 agent 环境，并用它测试 benchmark 结论是否在低成本环境中也能复现。

很多复杂平台难以用于教学和快速验证，而最小环境有助于分离核心机制，例如通信、占用冲突、局部危险事件、视觉到动作映射。它适合作为论文结论的‘机制复现实验台’。

第一步：先只实现 2D 版本的一个最小任务：两个代理、有限地图、占位规则和局部火灾事件，再比较有无通信、不同奖励信号下的行为变化。

风险：最小环境过于简化，可能无法承载原论文想讨论的复杂能力；而且若缺少原作者实现细节，复现出的结论可能只具有启发性而非可比性。

一句话

该论文提出两个可本地运行的最小化仿真基础框架：一个用于二维多智能体LLM社会仿真的SD-AgentFoundry-2D，另一个用于三维数字孪生场景中基于第一人称图像驱动VLM行动的SD-AgentFoundry-3D。其核心任务不是追求复杂应用性能，而是为教育、快速原型开发和可修改的生成式智能体环境提供低门槛起点。

Abstract Accumulating evidence demonstrates that the central nervous system (CNS) is not disconnected from the peripheral immune system; however, precisely how the adaptive immune system surveils the CNS remains a critical question. Recent findings reveal that channels between the skull and the dura mater facilitate the exchange of cerebrospinal fluid and immune cells between the CNS and skull bone marrow of mice under both homeostatic and disease conditions 1–6 . Skull bone marrow functions as a source of immune cells for the CNS 5 , yet its role in CNS antigen-specific adaptive immune responses remains unclear. Here we identify lymphoid structures within the skull bone marrow, featuring germinal-centre-like formations and containing a distinct population of follicular-helper-like T cells that promote B cell activation and humoral immunity through CD40L, IL-21 and IFNγ signalling. Adaptive immune cells within these skull bone marrow lymphoid structures surveil and respond to CNS-derived antigens and contribute to anti-tumour immune responses in mouse brain cancer models. Together, our findings show that the skull bone marrow is a site of CNS immunosurveillance that may influence immune responses across diverse neurological diseases.
