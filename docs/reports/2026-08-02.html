从题名和摘要看，论文聚焦的是分布式软件系统中的通信协议 refinement：当一个协议需要被新版本或变体安全替换时，如何保证它仍与其他组件兼容，并避免由于交互次序细微不一致导致的死锁。作者将这一问题放在形式化通信规范框架下处理，具体采用多方会话类型（MPST）作为规范语言，因为 MPST 天然适合描述多参与方之间的消息交换结构，并提供如 deadlock freedom 一类的严格行为保证。 方法上，Syntropy 不是单纯让 LLM 自由生成协议，而是“specification-guided synthesis”：把 refinement constraints 直接纳入生成过程。仅从摘要推断，这种纳入可能体现为：先由 MPST 给出原协议及其允许的 refinement 空间，再通过约束化提示、候选过滤、语法/类型检查、或迭代修正等机制，让 LLM 输出满足规范的协议变体。这里“ensuring the generated variants satisfy these guarantees”说明作者主张的不只是后验筛选，而更像在生成中显式编码约束。需要特别注意的是，摘要没有展开 Syntropy 的内部算法细节，因此还需核对它究竟是基于 constrained decoding、搜索+验证、模板化生成，还是 LLM 与形式验证器闭环交互。 证据线索主要来自摘要中的评测表述：作者称进行了 comprehensive evaluation，并在 multiple LLMs 上达到了 95.6%-99.5% validity，同时保持高 syntactic correctness，还能生成 diverse、non-trivial refinements。这说明实验大概率包含多个维度：第一，生成结果是否满足 refinement/类型/死锁相关约束；第二，语法或规范层面的可解析率；第三，不同 LLM 间稳定性；第四，结果多样性与复杂度，而不是只会做微小改写。但目前无法从摘要判断 validity 的精确定义，是指 MPST 类型有效、refinement 有效、可验证通过率，还是包含功能兼容性的复合指标；这一点必须回看正文和实验表格。 与相关研究方向的关系比较清晰：如果读者关注 LLM for formal methods、程序合成、协议验证、类型系统驱动生成，本文很值得看，因为它试图把“生成能力”与“形式行为保证”结合起来，避免纯 LLM 方法在协议设计上常见的不可靠性。对于从事通信中间件、分布式协作协议、协议演化与替换的人，这篇论文的价值在于它讨论的是 refinement synthesis，而不是从零开始设计协议，因此更接近真实系统中版本升级、局部优化、兼容扩展等任务。 需要核对的信息包括：1）refinement 的形式定义具体是什么，允许哪些行为变化、禁止哪些替换；2）deadlock freedom 是由 MPST 理论直接推出，还是还需额外检查条件；3）实验基准来自人工构造协议、已有 MPST 基准，还是工业场景协议；4）多样性与 non-triviality 如何量化；5）不同 LLM 的差异、成本与失败模式；6）Syntropy 对协议规模、参与方数量和分支复杂度的可扩展性。仅根据摘要，可以确认其研究定位和主要结果方向，但还不能判断方法新颖性的具体来源以及实验是否覆盖复杂真实协议。

原始摘要

Ensuring behavioural correctness in communication protocols is a central challenge in distributed software systems, as subtle inconsistencies can lead to deadlocks. In such settings, protocol refinement - the safe substitution of a protocol that preserves correctness and compatibility with other components - is essential. Large language models (LLMs) have demonstrated strong capabilities in code generation and program synthesis, yet lack mechanisms to reliably produce outputs with correct behaviour. Formal specification approaches, such as multiparty session types (MPST), offer rigorous guarantees, including deadlock freedom, but provide limited support for automatically constructing protocol refinements. In this paper, we present Syntropy, a framework for synthesising protocol refinements guided by MPST specifications and LLMs. It incorporates refinement constraints directly into the generation process, ensuring the generated variants satisfy these guarantees. Our comprehensive evaluation indicates that Syntropy achieves 95.6%-99.5% validity while maintaining high syntactic correctness, and produces diverse, non-trivial refinements across multiple LLMs.
