该论文针对 Craftax-Classic 这类稀疏奖励、长时程环境中的强化学习探索问题，提出用经环境特定数据微调的视觉-语言模型为智能体生成目标指导。根据摘要，作者构建了名为 CCGP-2M 的多模态目标偏好数据集，并通过离线微调加在线 goal-guided RL 的两阶段框架，在更早获取 diamonds、总体分数/奖励和多数 achievement 成功率上优于基线。
