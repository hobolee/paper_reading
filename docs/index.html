1. DConstrain: Compiling Context-Parameterized Transitions for Diffusion Language Model Constrained Decoding

⭐ 👍 👎
Shidong Cao、Jing Ma、Wenhao Chai、Yuchen Tian 等 6 人 · PDF
language model 1 language models 1 ai 1 diffusion 1 environment 1
一句话

这篇论文聚焦于扩散语言模型（Diffusion Language Models, DLMs）在受模式/语法约束解码时的精确推理问题，目标是在并行生成多个 token 的场景下，保证这些 token 组合后仍满足 schema 或 grammar 的全局兼容性。作者提出 DConstrain，通过把 schema 编译为“上下文参数化的转移程序”，在不预先枚举所有解析上下文的情况下，为 DLM 构造精确的受约束后继状态。

贡献

从摘要看，核心贡献是提出一种面向 DLM 约束解码的编译式框架 DConstrain：一方面用冷编译将 token 消费逻辑特化到局部语法状态，同时把栈操作、环境守卫和调用者相关的延迟解析保留为符号化上下文；另一方面用运行时的热编译把实际到达的解析配置绑定到这些程序上，从而精确构造后继而不依赖模型分数，并可与模型前向并行重叠。另一个重要贡献线索是以运行时值跟踪字段历史，支持任意属性顺序，避免以往精确解码器因状态爆炸而固定 property order、排除合法输出的问题；此外还引入 token-effect grouping，在运行前合并具有相同编译效果的 token，以降低运行时开销。

1问题

论文要解决的具体问题是：在扩散语言模型一次并行解码多个 token 时，如何在 schema 或 grammar 约束下进行精确解码，使这些 token 不仅各自合法，而且联合起来也满足全局结构约束；同时避免因显式编码解析栈、字段历史和调用上下文而导致编译状态指数爆炸。

2方法

从摘要推测，方法分为两阶段。离线的 cold compilation 将 schema/grammar 编译为上下文参数化的 transition programs：对局部 grammar state 上的 token 消费进行特化，但把依赖上下文的栈操作、环境守卫、延迟解析符号保留为符号参数。在线的 warm compilation 在解码时把实际到达的 parser configurations 绑定到这些程序上，构造精确后继图；由于该过程不依赖模型分数，可与 DLM 前向并行。为支持对象字段任意顺序，字段历史不再离线枚举为状态，而是作为运行时值跟踪；为降低开销，先按 compiled effects 对 token 分组，把具有相同效果的 token 合并处理。可能的实验对象是 JSON/schema 约束结构化生成或其他 grammar-constrained DLM decoding 任务。

3价值

最突出的亮点有三点。第一，问题抓得很准：DLM 的并行 token 解码确实比自回归 LM 更容易出现“局部合法、联合不合法”的结构冲突。第二，方法设计有明显的编译思想，把离线可特化部分与在线依赖上下文部分拆开，理论上有助于同时保留精确性和可扩展性。第三，摘要明确针对 prior exact decoders 的痛点——固定 property order、排除合法输出——提出运行时字段历史跟踪，这对 JSON/结构化对象生成很有实际价值。系统层面上，图构建与模型前向重叠、token-effect grouping 也显示出对推理效率的关注。
